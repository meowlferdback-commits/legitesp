ДЕМО ESP — Android-проект (исходники)
=====================================

Это автономный демонстрационный проект с тестовыми целями, а не модификация Standoff 2 / Standoff Remaster.
Он рисует рамки и ники над искусственными мишенями на экране. Сетевые данные игроков не читает,
в чужой процесс не внедряется и авторизацию Facebook не меняет.

Как получить APK:
1. Открой проект в Android Studio на компьютере.
2. Дождись синхронизации Gradle.
3. Выбери Build > Build APK(s).
4. Готовый debug APK появится в app/build/outputs/apk/debug/app-debug.apk.

Для сборки нужен Android SDK и подключение к интернету для загрузки Gradle-плагина.

Сборка через GitHub Actions:
- Загрузи содержимое архива в корень репозитория (ветка main).
- Открой Actions и выбери Build Android APK.
- Нажми Run workflow или дождись автоматического запуска после push.
- Скачай esp-demo-debug-apk из Artifacts у успешного запуска.
